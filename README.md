# 月间 · 日历与照护

面向伴侣共同使用的中文开源经期工具，以日期为中心保存实际情况、四个领域的 AI 分析和后续对话。

[在线使用](https://yuejian-personal-journal.soundteal2049.chatgpt.site/#calendar) · [开源仓库](https://github.com/wangkeyu-u/yuejian-care)

## 三个模块

### 日历

点击日期打开当天对话框。可以保存疼痛、精力、心情、睡眠、出血、支持方式和文字记录，主动生成玄学、中医、西医、心理学四块 AI 分析，再继续提问。

四块内容由 API 返回，未接入或未生成时明确显示等待状态。日期定位、参考预测和医疗优先提示由本地规则计算并标明，不冒充 AI 输出。

分析、对话按日期隔离。追问带上这一天的最新四块分析、实际情况和最近 6 轮消息；本机最多保留每个日期 50 轮对话。重要新情况需要保存到当天记录，聊天不会自动改写经期。重新生成会把上一版分析与对话保留为一份 previous 快照，并开始新一段对话。

### 照护百科

保留 48 篇有出处的资料：22 篇经期健康、8 篇中医、18 篇传统文化。筛选轴分为：

- **领域**：西医与身体、中医与疗法、心理与睡眠、玄学与历法。
- **问题**：周期日期、疼痛不适、饮食活动、睡眠情绪、用品清洁、用药就诊、历法文化。

一篇资料可属于多个领域，例如睡眠同时出现在西医与心理筛选中；资料性质和来源核对日期独立显示。支持搜索、收藏、逐段引用和“带着这条问今天的 AI”，不会自动发起 API 请求。

### 设置

集中管理 OpenAI API Key、模型、实际经期起止、参考参数、本人偏好、回答详细程度、关注主题、可选文化信息，以及导出、导入和恢复备份。

- 设置保存后，日历、预测和已打开日期的上下文立即刷新。同一浏览器同一网址的其他标签页通过 storage 事件更新。
- 周期数据使用稳定记录 ID。开始日改变会重算位置和预测；结束日只修正实际出血范围；感受记录保留原公历日期。
- 相关记录或模型/偏好改变后，旧 AI 分析标为过期，暂停继续追问，重新生成后再用新上下文。迟到的旧响应不会覆盖新记录。
- Key 默认留在当前标签页会话中，刷新可继续使用；取消勾选时只保留于当前页面内存。Key 不进入经期数据、对话存储和导出文件。清除 Key 保留其他记录。

## AI 和资料范围

仅支持 OpenAI Responses API，默认 `gpt-4.1-mini`，可选择账号有权限、支持结构化输出的 `gpt-*` 模型。填写 Key 不会自动付费；每次生成或提问由用户主动确认并提交，费用由该 Key 的 API 账号承担。

浏览器向同源 `/api/day` 发送用户确认的白名单资料，服务端验证、重算日期和文化符号、选取已核对文章，再转发至固定的 OpenAI 接口。API Key 仅用于请求头，应用不记录请求体或 Key；使用 `store:false`，不承诺托管平台或 OpenAI 零保留。

昵称、城市不进入模型输入。生日仅在文化功能开启并由本人确认时用于服务端历法计算，模型获得干支/生肖等符号与口径说明，不获得原始生日。文字小记、明确偏好、当前问题和本日对话属于可发送资料，调用前有预览和同意选项。

西医与心理资料用于健康与情绪照护信息，中医区分传统理论、疗法证据和适用条件，玄学作为文化解释和可选灵感。不由生日、MBTI、五行推断体质、诊断、喜好或健康禁忌，不补猜出生时间或完整八字。

服务端限制输出结构、四块领域唯一性和引用 ID；不完整、拒答、未知或跨领域来源会被拒绝。来源 ID 合法不保证模型每句话都受原文支持，用户仍需核对。严重疼痛或异常出血的本地医疗优先提示持续可见。

## 数据与迁移

实际数据保存在当前浏览器，无自动云同步。旧 `starts` 迁移为结束未知的实际记录，不补造结束日；旧 v2 经期、日记和偏好继续读取，原日期不变。旧入口 `#today` 转到日历，`#journal` / `#about` 转到设置。

导出包含经期、感受、偏好、每日 AI 分析/对话、百科收藏及迁移备份，排除 API Key。导入前显示替换范围并备份原数据，可恢复导入前状态。读取损坏的数据时暂停相关写入，原始数据可导出。

同一设备的其他使用者可能看到本机记录。请由当事人选择愿意分享的信息，清理浏览器或更换设备前导出备份。不要在公开 Issue、截图、PR 中上传真实经期、生日、对话或 Key。

## 本地运行

Node.js 22.12+（本次测试使用 Node.js 26）：

```sh
npm ci --ignore-scripts
npm start
```

打开 `http://127.0.0.1:4174`。修改源码后重启开发服务器。

```sh
npm test
npm run build
npm run validate
```

- `public/state.js`：兼容迁移、存储和变更通知。
- `public/day-context.js`：前后端复用的日期上下文、签名、来源选择与文化符号。
- `public/day-chat.js` / `day-sessions.js`：当天对话 UI 与按日期保存的会话。
- `public/catalog.js` / `library.js`：双维度分类、检索、收藏和原文阅读。
- `public/app.js`：三个模块的装配、日历与设置。
- `worker/day-ai.mjs`：四领域分析及连续问答；`worker/ai.mjs` 保留旧 `/api/analyze` 契约供旧页面过渡。
- `dist/server/index.js`：生成的单文件 ESM Worker，内嵌页面资源并导出 default.fetch。

自部署需同源 Worker API；仅静态托管 public/ 可以记录与浏览百科，不能调用 AI。构建不需要原站 Site ID 或 API Key。Sites 部署身份保留在部署实例的 `.openai/hosting.json`。

测试包括日期、迁移、资料引用结构、设置联动、日期会话隔离、历史消息传递和模型错误处理。API 上游使用模拟响应，尚未用真实用户 Key 验收付费调用；浏览器复验使用本地虚构记录，不代表实体设备或医学疗效验证。
