# 知识来源与核对规则

本次核对日期：2026-10-26。记录描述这一次读取到的来源，不代表文章已接受独立医学审稿，也不保证来源今后不会更新或失效。

## 如何阅读网站里的引用

- 每篇显示资料性质、核对日期和逐条来源的支持范围。每段末尾的 `[1]` 等链接指向该篇列出的对应原文。
- “医学资料”表示健康机构资料或研究综述，不是统一的证据等级，也不等于每项建议均由随机试验验证。
- “传统理论”用于介绍中医或传统文化的术语与解释，不能直接当作现代生物医学机制或个人诊断。
- “编辑建议”包括网站操作、照护沟通、日程安排与自选仪式；不会冒充古籍原话或研究结论。
- “资料与编辑整理”表示一篇中同时包含有来源的事实和明确标注的编辑说明。请结合每个链接下方的支持范围阅读。

## 核对方式

1. 实际打开原文，核对标题、发布机构以及该段是否能支持对应事实。
2. 优先采用政府卫生部门、官方医疗机构、专业机构和可读的研究综述。医院科普可以支持其如何解释传统理论，不能单独证明疗效。
3. 引用局限和适用范围与结论一起保留；旧综述注明检索年代，不能据此声称已掌握截至今日的全部研究。
4. 无法访问、只见摘要片段或不支持正文的链接，不作为唯一依据。删除或缩窄无法核实的事实，不用相近主题的首页代替证据。
5. 中药、针灸、艾灸等不生成自动辨证、个人药方、药量或自我操作教程。需要医疗评估的症状不由日历、生日或五行判断。
