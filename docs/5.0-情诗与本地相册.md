# 5.0 情诗与本地相册

2026-10-30。新增第四个导航入口「情诗」；原有日历、照护百科、设置保留。

## 记下一句话

输入已发生的记事，选择参考日期并允许发送文字后，点击「写成情诗并记下」。AI 提取事件、给出标题和短诗；本地与服务端均检查日期和逐字原句。支持中文数字年月日、ISO 日期、月日与相对今天/昨天/前天；不明确的上周等表达要求补充日期。没有明确日期时使用页面所选参考日。未来约定不作为已发生记录保存。

原句、来源全文、短诗、实际日期、生成模型与时间分别保留；也可以先存原文或亲手写诗。修改日期和文字后，日历立即刷新，引用原文的旧回顾标为有更新。日历以小菱形标记有回忆的日期；点开当天，先读到回忆与诗，再进入照护内容。情诗和健康档案分别保存，原始记事不自动变为健康记忆。

## 周 / 月 / 年回顾

以原文和实际日期为输入，生成诗意回信，选取片段逐项引用原记录 ID 与原句，可打开对应日期。不会发送经期、健康偏好、照护聊天或照片。引用对照能验证片段存在，不能保证模型的文学表达完全符合个人审美；可自行修改记事后重新生成。

手动生成可选择周、月、年和参考日；尚未结束的周期说明只含截至目前记录。开启「页面打开时自动回顾」并允许发送文字、配置 Key 后，在页面加载、重新获得焦点或前台定期检查刚结束的周期。一次只启动一份，优先年/月/周，有记录才生成；每个周期仅自动尝试一次，失败不自动重试。已生成或删除过的回顾不自动反复生成。关闭页面时不会运行，不提供后台定时推送。

单次请求最多256KiB、1500条来源；超出时明确提示缩小范围，不静默截掉原文。没有记录的日子不补写。

## 相册与删除

照片仅写入当前站点来源下的 IndexedDB，使用本机 Blob URL 显示；不放入 Git、公开静态资源、AI 请求或服务端存储。支持一次30张、单张12MiB以内的 JPEG/PNG/WebP，检查文件类型与签名；不改变原图。拍摄日期可以留空，也可逐张修改；有日期时出现在对应日历。没有从照片外观推断拍摄日期、地点或身份。

记事、照片和回顾删除均经过：打开具体对象 → 填写至少4字理由 → 查看影响与理由 → 输入「让这页轻轻合上」 → 明确点击删除。先移入回收匣，可以恢复。永久删除需再走一次理由与确认，并明确提示无法从回收匣恢复；永久删除照片会同时删除图片 Blob。不会删除用户电脑上的原始文件。

删除记事会清理引用它的派生回顾。导入保留已删除标识，避免旧备份把内容带回；合并只增加未存在、未被删除的记录，不覆盖当前版本。永久删除屏障也随备份迁移。已下载到别处的备份不能被网站远程清理。

## 备份与边界

「情诗与照片」使用独立 JSON 备份，包含图片、回忆、回顾、回收匣与删除标识，不含 Key 或健康档案。设置中的照护备份不包含相册；界面已标明两个入口。设置中的「清空照护记录」保留情诗与照片，避免绕过新模块的删除确认。

当前限额为2万则记事、5000张照片、3000份回顾；实际容量取决于浏览器。恢复文件上限128MiB。使用浏览器本地保存，清理该站点的浏览器数据会丢失未备份内容；不同浏览器/设备不会自动同步。

## 验证

- 自动测试覆盖日期解析、闰年/跨年范围、无依据日期与引用拦截、同源/同意/模型校验、AI 数据最小化、IndexedDB 写入与并发冲突、日历即时刷新、多步删除、防旧备份恢复、自动回顾只运行一次及延迟响应不能覆盖新数据。
- 浏览器使用给定6张照片验证本地添加、读取、刷新保留、查看、删除取消；所有图片使用 Blob URL，未进入公开目录。
- 浏览器用合成模型响应验证整句 → 诗 → 日期开头，以及月度回顾与原文链接。真实导出含1则测试记事、1份测试回顾、6张照片，全部图片大小核对一致，合并恢复后仍为6张，无重复。
- 本轮没有新增付费模型调用；不能将合成响应或接口测试称为真实模型质量验证。
- 手机视口与最终公开部署按交付结果核对；不宣称实体手机长期运行认证。
