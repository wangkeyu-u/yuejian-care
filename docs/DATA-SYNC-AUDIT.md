## 找到并修复的5项问题

| 问题 | 修复后的行为 |
| --- | --- |
| 文化分析关闭后，前端请求预览仍带已保存生日和出生时间 | 关闭文化或生日未经确认时，浏览器发送范围不带出生资料；本地编辑值保留。 |
| 导入更换服务商后，未保存的旧Key输入仍留在表单 | 成功导入/恢复后清空未保存Key输入，不能把原服务的输入误保存到新服务。已配置Key仍按服务独立管理。 |
| 清理某天AI对话时，把其他日期的感受草稿一并清掉 | 取消旧请求与丢弃草稿分开；清理单日对话保留其他草稿，成功替换完整档案才重置草稿。记忆清理屏障仍会排除失效来源。 |
| Key会话存储失败，但服务商/模型已先写入档案 | 先确认Key可保存，再写服务设置；档案写入失败则恢复原Key及其保留方式，不把失败保存变成半更新。 |
| 清空本机记录后，未保存的Key输入仍留在密码框 | 清空成功时同时重置该输入、设置草稿与当天草稿。 |

失败导入仍保留原档案、未保存的Key输入和感受草稿；没有将失败流程当作成功替换。
