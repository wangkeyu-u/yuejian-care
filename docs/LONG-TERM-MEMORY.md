# 以人为中心的记忆 · 4.3

记忆是经过用户核对的报告，不是 AI 对一个人的定论。当天明确记录与本人当下表达优先。生日、MBTI、依恋标签、文章和助手输出不能成为个人事实的来源。所有记忆仍在当前网站的浏览器 localStorage，没有云端人物数据库。

## 两种记忆、两种日期

- **长期背景**：持续或反复偏好、明确报告的过敏、健康情况、用药等。保留原来的条件、来源日期与表达者（本人、伴侣转述、未知）。
- **短期状态**：某一天明确报告的临时感受或需求。候选默认从来源日到次日，共两个公历日期；采用前可修改。这是产品保留策略，不是医学持续时间。有效期结束后不用于当前日期，原历史日期仍可回看。
- **实际有效截止日 `until`**：决定适用于哪一天。空值表示没有声明结束，不表示永久真实。
- **复核日期 `reviewAt`**：独立于有效期。到期后显示待复核，发给 AI 时标明先确认；不自动宣布停药、痊愈或过敏消失。手动“已重新核对”记录 `reviewedAt` 并安排下次复核。

用药默认30天后复核，其他长期候选/手动新增默认180天后；均为可修改的工程默认值，不是医学标准。v1 界面曾将 `until` 称为“复核截止日”，迁移时将其转为 `reviewAt`，实际 `until` 清空，避免旧用药条目悄悄消失。首次普通保存会留下 `yuejian.memory.pre-v2` 本机迁移备份。

## 近期记录与按问题选取

日期上下文最多参考所选日期之前两个公历日、且已经发生的实际情况。身体问题选择相关身体字段；睡眠、陪伴、饮食问题按主题选择字段或相关小记；文化问题不附带不相关身体记录。每条均带原日期，明确今天是否延续未知。其他日期的整段聊天不发送，也不会自动总结为长期模式。

记忆在浏览器发出请求前按类别、关键词和用户指定主题选择，不是语义向量检索。综合分析优先相关性，最多8条普通背景，加适用的健康/用药/过敏报告，总量不超过24条。身体、饮食、情绪、睡眠问题保留相关风险报告；纯文化问题不附带这些报告。未知表述可能路由不准，可手动选择关注主题并展开发送预览。

所选背景变化时，浏览器不会把旧分析或旧对话再带给模型，以免旧摘要绕过记忆选择。只在记忆与近期资料选择相同的情况下沿用本日对应分析/当前话题段，最多最近6轮；完整本日历史仍本机保留最多50轮供查看。界面显示实际选择和近期来源日期。

## 提取、核对与提示词

普通分析/追问最多4条候选；设置可单独从最近20条小记或用户发言提取，每条最多500字，独立确认发送，最多8条候选。服务器和浏览器核对 sourceId、逐字引文、日期和秘密字符串；长期候选还要求持续性表述，临时状态只能为短期。所有候选均需人确认；自动提取可关闭。规则校验不能证明语义、医学真实性或否定条件理解正确。

静态照护规则与动态背景分开。选中记忆以转义 JSON 数据块附加到 Responses `instructions`，不复制来源全文，不把记忆文本当行为指令。包含范围、实际日期、复核状态与表达者；反复提醒旧状态不是今天事实、报告不是医学确证。查看预览不需要 Key，也不发 API。

## 更正、变化、停止使用和删除

- **更正原内容**：原说法有误。生成新版本，保留 rootId 和 supersedes；旧版本在任何日期都不再使用。来源仍可查看，但停止作为 AI 背景或重新提取来源；相关分析失效。新版本由本次人工核对授权，保留来源链用于追溯与后续清理。
- **从某日发生变化**：之前正确、后来改变。旧版本以变化前一天结束，历史日期可用；新版本从填写的起始日生效。旧分析需更新。
- **停止使用**：保留记忆与原文供本机查看，停止跨日使用/来源再提取，使依赖它的旧分析失效。不会把停止使用理解为事实已经消失。
- **删除并清理来源**：先预览，确认后删除整条版本链、关联日期的原始情况、整日对话/分析及 previous 快照，并沿 sourceDates 依赖清理派生会话。旧记录缺依赖标记时使用原句/内容匹配；关联不清晰时按整日清理，预览可能包含同日其他内容。

更正、停用与删除会先取消正在进行的回答/提取，提交后统一刷新。保存了版本依赖 memoryIds、根依赖 memoryRoots、来源日期 sourceDates。新签名是上下文摘要指纹，旧签名中的原文也随关联会话清理。指纹用于缓存、去重和防止旧备份复活，不是加密或身份认证。

隐私操作同时处理主资料、每日会话和四份本机自动备份（旧经期迁移、旧记忆迁移、导入前主资料、导入前整包），清理记录不保存原句。localStorage 无多键原子事务：先在内存计算、核对快照，再提交；失败尝试回滚并报告未完成，不显示成功。主资料损坏时暂停写入；每日存储损坏时删除预览明确提示将整体清理该部分。

当前清理屏障会保留在导入/恢复流程中，拦截旧版本与关联原始来源。主动在同一天重新填写资料会确认现有屏障，让新资料可以使用；不会自动重新采用被删除的原事实。屏障确认只是本机数据机制。已下载/复制到外部的备份、服务商已收到的请求，无法由网站追溯删除；需在各自位置处理。清空整个浏览器档案也会清空屏障，此后从外部旧文件开始相当于新档案。

## 验证范围

自动测试覆盖迁移、两个日期边界、历史变化、主题选择与旧对话隔离、更正后再生成、晚到响应、来源再提取、删除范围、依赖传播、备份清理/导入防复活、跨标签页冲突和写入失败。API 使用模拟上游；未用真实 Key 验收语义选择、提取准确性、健康有效性或付费账号权限。
