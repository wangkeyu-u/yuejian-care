# 4.10 长期链路与逐项依据

2026-10-30。数据仍保存于使用者当前浏览器；没有新增云端档案或自动 AI 请求。

## 结果与依据的对应

新生成的完整分析必须覆盖摘要、启用的领域、每个行动、饮食原则和每顿饭；追问必须覆盖回答及每个行动。共享同一依据的同领域内容允许合并一个依据组，但每个输出位置只属于一个组。

每组保存：本次可用的记录 ID、所选文章正文的逐字摘录、段落位置、该段原始来源链接、AI 对适用关系的简短解释、未知与适用边界。记录快照区分当天输入、前两日历史、偏好、长期背景和阶段估算；记忆附来源日期、表达者、有效范围、复核日期。

服务端检查目标是否完整、记录是否来自本次上下文、摘录是否出现在文章正文、引用是否属于对应领域。没有逐项依据、伪造记录、段落找不到或错放领域则不保存，不自动重试。站内规则改写的行动切换到规则依据，不继续沿用模型原来的解释。过往分析没有这份结构时标明缺少逐项依据，不事后编造。

**引用匹配不是医学验证。** 目前检查能证明引用存在、位置对应、数据来源可追溯，不能自动证明自然语言的全部推断都被文献支持。模型解释需和原文、个人情况一起核对；测试不表示预测准确率、疗效或诊断能力。配餐仍为普通组合示例。

## 长期链路修复

- 修复短期状态排序加分导致无关记忆进入其他话题：先判断相关性，再排序；健康、用药、过敏等已有关键约束规则保留。
- 从原句提取记忆时，拒绝原句没有的数字事实。允许把原句的来源日期规范化为公历或月日；不允许把另一个输入字段的疼痛分数偷偷写进仅引用小记的候选。这个检查不是完整语义蕴含判定，候选仍需本人核对。
- 保留已确认、独立复核、有效截止、更正版本、停止使用、彻底删除及防旧备份恢复屏障。到复核日不代表病情消失、停药或过敏解除。
- 依据快照随原有会话依赖一起保存和清理。资料改变后旧分析失效；不靠改日期让旧依据重新变成当前结论。

## 验证记录

自动回归覆盖前端实际表单到正式 Worker 的串联：提取候选 → 核对确认 → 跨日调用 → 更正 → 删除 → 旧备份无法恢复。另覆盖短期到期、长期复核、跨话题筛选、引用遗漏/造假/错领域、依据保存和刷新、旧数据兼容。全量结果见交付时测试输出。

一致性审计比较450个历史日期的日历/分析投影，核对58篇资料、6本书、172段正文的155个来源映射；5年与10年合成记录用于运算检查，不能视为实体手机运行多年或临床验证。
