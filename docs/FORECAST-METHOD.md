# 周期参考预测

这是可复算的日期统计，不是经临床验证的机器学习模型。AI只解释这份计算，不自行改写下一次日期。

- 最近最多7次实际开始日形成最多6个相邻间隔。
- 至少3次实际开始日且所有这些间隔均在15—90天时，使用间隔中位数四舍五入作为本次参考周期。
- 不足3次记录或有超出该工程范围的间隔时使用手动参考周期，保留并说明全部异常间隔；不默默删除数据。
- 历史窗口为已观察最小间隔减2天至最大间隔加2天；手动窗口为参考周期±3天。它们是工程余量，不是置信区间、准确率或医学正常范围。
- 预测到期未记录新开始日时保持原参考日期，不自动滚动。最近经期仍进行中且已达到参考下次开始日时暂停新一轮预测。
- 修改开始日会重算统计、下一次日期、周期位置和日历；修改结束日改变实际出血区间，不重置下一次开始日。修改记录会让已有AI分析失效。
- 无法判断排卵、安全期、怀孕或周期变化原因。个体波动和漏记均可能造成明显误差。
