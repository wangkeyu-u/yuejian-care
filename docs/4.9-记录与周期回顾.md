# 4.9 记录与周期回顾

参考来源（2026-10-29 核对）：[美柚官方应用介绍](https://www.meiyou.com/mobile.html)公开介绍了记录、预测和提醒。月间据此改进常用入口；本次未安装或登录美柚，也未核验其内部算法。周期回顾的统计规则是本站设计。

- 日历“记今天”直接打开当天感受表单，轻微腹痛/睡不好/想独处三个快捷项可取消。只变更本次草稿，明确保存后才写入本地、刷新 AI 预览。原有按日期保存、草稿冲突和隐私屏障继续生效。
- 周期详情展示最近7次实际经期，间隔定义为本次实际开始到下一次实际开始，统计最多6个间隔；最后一轮显示待下一次记录。未确认结束不填出血天数；进行中天数按公历包含开始当天计数。
- 统计包含可见记录中的全部实际间隔，不静默删除离群值。间隔含小于15天或超过90天的记录时展示核对提示，并沿用预测模块的手动参考回退；15/90是本应用拟合规则，不是健康诊断标准。
- 间隔中位数可为小数；下次参考仍沿用原预测模块的四舍五入。倒计时不代表实际到来时间，也不自动新增经期或确认排卵。
- 修改/删除/撤销经期、导入与同源多标签页更新走原有 store 通知，回顾、倒计时与 AI 原始输入一起刷新。快捷记录不调用模型；未新增通知权限或后台推送。

验证：243项自动化检查、构建和 Worker 校验通过；实际浏览器使用合成资料核对回顾表、改期后的即时统计/倒计时及快捷项保存后的请求预览。该版本没有付费 API 调用。
