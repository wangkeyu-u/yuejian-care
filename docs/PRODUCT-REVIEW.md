# 三模块结构复核 · 2026-10-28

## 已落实

- 导航收敛为日历、照护百科、设置。感受记录和 AI 对话归属日期，实际经期与个性化归属设置。
- 当日四领域分析和连续问答共享同一份经过清洗的日期上下文，日期之间隔离；设置保存触发重新渲染并使旧分析失效。
- 未接入 Key 或没有模型响应时显示等待状态；本机日期计算、求助规则与 AI 文字分别标明。
- 百科分开领域、问题和证据性质三个维度。心理睡眠与西医允许交叉归类；文章仍保留原文及段落支持范围。
- 旧 v2 数据、原公历日记与收藏继续保留。新旧窗口使用过期编辑保护；迟到 AI 响应不能覆盖新上下文。
- API Key 与数据备份分离。API 请求由用户主动提交；昵称不进模型，文化计算不向模型发送原始生日。
- 原生 HTML/JS 的界面模块与 Worker 服务分离，上下文构建复用于前后端。当前规模可继续维护；模块已拆开，后续可以按需要逐步迁移组件。

## 值得继续做的功能

1. **双方授权与多设备同步**：当前只在同一浏览器同步。若双方要各自用手机，需要账号、配对、可撤回共享范围与服务端存储；不应把同浏览器刷新包装成云同步。
2. **本人确认的长期事实档案**：可加入可选的过敏、正在用药、本人已确认的长期情况，并区分“本人报告”与“医生确认”。会影响敏感数据发送范围，需要独立勾选和预览；不能由聊天或标签自动推断。
3. **调用成本与长对话体验**：显示实际 token 用量、流式回答、单日预算与重试按钮。当前每次主动请求，传最近6轮，本机最多50轮；更长记忆可以加带来源与确认状态的摘要，避免把猜测变成事实。
4. **知识维护与输出评估**：为资料建立更新时间、失效检查、证据等级和撤回流程。构建包含来源版本的回归案例，专门检查 AI 是否把未填信息写成症状，或把引用存在误当成论证充分。
5. **更完整的版本与数据管理**：目前保留上一版分析快照，但回看 UI 和逐日对话清理还可补足；可添加单日导出、对比、恢复以及更清楚的存储容量提示。

## 验证边界

真实 API 账号的额度、权限和模型输出尚需用户在网站填 Key 后验收；模拟测试不替代真实服务。浏览器验证覆盖桌面与390px布局，不能代表所有手机、辅助技术或医学有效性。参考预测窗口是工程余量，不是临床置信区间。
